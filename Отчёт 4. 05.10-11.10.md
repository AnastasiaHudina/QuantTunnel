# Отчёт о проделанной работе

**Период:** 5.10 – 11.10
**Проект:** Интерактивный симулятор квантового туннелирования на основе PINN

## Ссылка на репозиторий

https://github.com/AnastasiaHudina/QuantTunnel

## Структура репозитория

```
QuantTunnel/
├── README.md # описание проекта и физической постановки
└── ML_QuantTunnel/
├── README.md # пояснение к структуре ML_QuantTunnel
├── configs/  # генератор физических конфигураций
├── physics/  # физический модуль
└── scripts/  # скрипты проверки
```

В корневом `README.md` выписана полная физическая постановка: уравнение Шрёдингера, переход к системе для $u$ и $v$, потенциалы барьера и ямы, начальное условие, граничные условия, аналитические формулы для $D$. Для каждой формулы указан источник: учебник [1] и задачник [2].

## Что было сделано

- **Физический модуль** (`physics/`):
  - `constants.py` — система единиц ($\hbar = 1$, $m = 1$);
  - `potentials.py` — потенциалы барьера и ямы;
  - `initial_condition.py` — гауссов пакет и его нормировка;
  - `boundary_conditions.py` — граничные условия и проверка выбора $L$;
  - `analytics.py` — аналитические формулы для $D$.

- **Генератор конфигураций** (`configs/generator.py`):
  - стратифицированная генерация параметров для барьера (режимы $\varepsilon < W$, $\varepsilon \approx W$, $\varepsilon > W$ в пропорции 40 / 20 / 40);
  - разбиение на train / val / test (70 / 15 / 15) по конфигурациям;
  - сохранение в JSON.

- **Скрипт проверки физики** (`scripts/check_physics.py`):
  - прогоняет все проверки: нормировку пакета, форму потенциалов, аналитику $D$, работу генератора, граничные условия.

## Результаты проверок

**Успешно:**
- Нормировка: $\int |\psi|^2 dx = 1.0000000000$.
- Резонанс в яме: $D = 1.000000000000$ (точность $10^{-10}$).
- Генератор: 800 / 400 / 800 конфигураций по режимам, split 1400 / 300 / 300, все режимы во всех частях.
- JSON сохраняется и загружается без потерь.

**Найдены и исправлены две проблемы:**

1. **Неверное ожидание в тесте аналитики.** Изначально предполагалось $D \to 1$ при $\varepsilon \to W^-$, но правильный предел $1/(1 + k_W^2 d^2/4) \approx 0.667$. Ошибка была в тесте, не в коде. Тест заменён на проверку монотонности $D$ по $\varepsilon$ при $\varepsilon < W$.

2. **Недостаточный $L$.** При $L = 20$, $T = 5$ у 319 из 2000 конфигураций барьера и у 82 из 500 конфигураций ямы пакет долетал до границы. Это физически некорректно: условие $\psi(\pm L) = 0$ превращается в реальную стенку и искажает задачу рассеяния. Выбрано новое значение $L = 35$ — при нём все конфигурации проходят проверку с запасом.
