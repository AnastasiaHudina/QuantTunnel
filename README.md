# Интерактивный симулятор квантового туннелирования на основе PINN

Репозиторий для кодовой реализации проекта: моделирование одномерного временного уравнения Шрёдингера с помощью Physics-Informed Neural Networks (PINN).

## О проекте

Цель – разработать веб-приложение, которое моделирует движение квантовой частицы через потенциальный барьер или яму. Вместо классических численных методов используется PINN: нейросеть, которая обучена на уравнении Шрёдингера и может выдавать решение мгновенно.

Ключевая особенность – режим верификации: сравнение результата PINN с аналитическим решением.

## Физическая постановка

### 1. Уравнение Шрёдингера (TDSE)

Моделируется одномерное движение квантовой частицы массы $m$ в потенциальном поле $V(x)$. Исходное уравнение:

$$i\hbar \frac{\partial \Psi}{\partial t} = -\frac{\hbar^2}{2m}\frac{\partial^2 \Psi}{\partial x^2} + V(x)\Psi$$

*Источник: [1], стр. 109, формула (2.164).*

Для PINN комплексная функция представляется как пара действительных:

$$\Psi(x,t) = u(x,t) + iv(x,t)$$

*Представление: следствие [1], стр. 109, формула (2.164); используется для перехода к действительным функциям.*

Тогда система уравнений для $u$ и $v$ принимает вид:

$$\frac{\partial u}{\partial t} = -\frac{\hbar}{2m}\frac{\partial^2 v}{\partial x^2} + \frac{V(x)}{\hbar}v$$

$$\frac{\partial v}{\partial t} = \frac{\hbar}{2m}\frac{\partial^2 u}{\partial x^2} - \frac{V(x)}{\hbar}u$$

*Источник: получается подстановкой* $\Psi=u+iv$ *в [1], стр. 109, формулы (2.162 – 2.164).*

### 2. Потенциалы

#### Прямоугольный барьер

$$
V(x) =
\begin{cases}
0, & x<0 \text{ или } x>d, \\
W, & 0\le x\le d.
\end{cases}
$$

*Источник: [2], стр. 157, рис. 5.4, задача 5.4.*

#### Прямоугольная яма
$$
V(x) =
\begin{cases}
0, & x<-a \text{ или } x>a, \\
-U_0, & -a\le x\le a.
\end{cases}
$$

*Источник: [2], стр. 150, рис. 5.3, задача 5.3.*

### 3. Начальное условие

В момент $t=0$ частица задаётся гауссовым волновым пакетом, движущимся слева направо:

$$
\Psi(x,0) = \frac{1}{\sqrt[4]{\pi b^2}} \exp\left(-\frac{(x-x_0)^2}{2b^2} + i k_0 x\right)
$$

где $b$ – ширина пакета, $x_0<0$ – начальное положение центра, $k_0$ – волновое число.

*Источник: [2], стр. 110–111, задача 4.1. Нормировочный множитель* $C=(\pi b^2)^{-1/4}$ *выбран из условия* $\int|\Psi|^2\,dx=1$*.*

### 4. Граничные условия

На границах области $x=\pm L$:

$$\Psi(-L,t) = \Psi(L,t) = 0$$

что эквивалентно

$$u(-L,t) = u(L,t) = v(-L,t) = v(L,t) = 0.$$

*Источник: [1], стр. 110 (обсуждение граничных условий).*

### 5. Аналитические формулы для валидации

#### Барьер, $\varepsilon<W$ (туннелирование)

$$D = \left(1 + \frac{(k^2+\kappa^2)^2}{4k^2\kappa^2}\,\sinh^2(\kappa d)\right)^{-1}$$

$$k = \frac{\sqrt{2m\varepsilon}}{\hbar}, \qquad \kappa = \frac{\sqrt{2m(W-\varepsilon)}}{\hbar}$$

*Источник: [2], стр. 158, задача 5.4, формула (5); также [1], стр. 131, формула (3.47).*

#### Барьер, $\varepsilon>W$ (надбарьерное прохождение)

$$D = \left(1 + \frac{(k_1^2-k_2^2)^2}{4k_1^2 k_2^2}\,\sin^2(k_2 d)\right)^{-1}$$

$$k_1 = \frac{\sqrt{2m\varepsilon}}{\hbar}, \qquad k_2 = \frac{\sqrt{2m(\varepsilon-W)}}{\hbar}$$

*Источник: [2], стр. 149, задача 5.2, формула (8).*

#### Яма, $\varepsilon>0$

$$D = \left(1 + \frac{(k_1^2-k_2^2)^2}{4k_1^2 k_2^2}\,\sin^2(2k_2 a)\right)^{-1}$$

$$k_1 = \frac{\sqrt{2m\varepsilon}}{\hbar}, \qquad k_2 = \frac{\sqrt{2m(\varepsilon+U_0)}}{\hbar}$$

*Источник: [2], стр. 150, задача 5.3, формула (2).*

Резонанс: $2k_2 a = \pi n$. Внутри ямы чётные состояния $\sim\cos(k_2 x)$, нечётные $\sim\sin(k_2 x)$.

*Источник: [2], стр. 152, задача 5.3, пункт (6).*

### 6. Свободное движение (тест $V=0$)

Для проверки начального условия и эволюции пакета:

$$\Psi(x,t) = \int \frac{dp}{2\pi\hbar}\,a(p)\,e^{\,i(px-\varepsilon_p t)/\hbar}, \qquad \varepsilon_p = \frac{p^2}{2m}$$

*Источник: [2], стр. 117–119, задача 4.2, формулы (4), (5).*
