# План валидации PINN-модели

Этот документ фиксирует, **как именно** мы проверяем, что обученная нейросеть (PINN) правильно решает уравнение Шрёдингера. План составлен на основе задач из учебника [1] и задачника [2].

Мы движемся строго по шагам. Если текущий тест не пройден, переходить к следующему **нельзя**.

## Общие принципы

1. **Разделение данных.** Обучение, валидация и тест выполняются на разных физических конфигурациях (см. `configs/generator.py`). Тестовые конфигурации не используются при обучении.
2. **Аналитические эталоны.** Для каждой задачи есть точное аналитическое решение или формула из задачника, с которой сравнивается результат сети.
3. **Интегралы по конечной области.** Везде, где в теории стоит интеграл до бесконечности, на практике используется конечная область $[-L, L]$. Условие применимости: пакет не должен достигать границ за время моделирования (проверяется функцией `check_L_sufficient`).
4. **Сохранение нормы.** Норма волновой функции $\int |\Psi|^2 \, dx = 1$ должна сохраняться с точностью до $10^{-3}$ во всех тестах.

## Тест 1. Свободное движение ($V=0$)

**Цель:** убедиться, что сеть правильно воспроизводит эволюцию гауссова пакета без потенциала.

**Эталон:** аналитическое решение задачи 4.2 из задачника [2, стр. 117–119].

**Что проверяем:**

1. **Движение центра пакета:**

$$
\langle x \rangle(t) = x_0 + v t, \quad v = \frac{\hbar k_0}{m}
$$

Ошибка не должна превышать 2%.

2. **Расплывание пакета:**

Параметр огибающей $b(t)$ растёт как

$$
b(t) = \sqrt{b^2 + \left(\frac{\hbar t}{m b}\right)^2}
$$

*Важно:* стандартное отклонение плотности вероятности $|\Psi|^2$ для гауссова пакета равно $\sigma(t) = b(t) / \sqrt{2}$. Именно с этой величиной нужно сравнивать ширину пакета, извлекаемую из предсказания сети. Ошибка $\sigma$ не должна превышать 2%.

3. **Сохранение нормы:**

$$
\left| \int_{-L}^{L} |\Psi(x,t)|^2 \, dx - 1 \right| < 10^{-3}
$$

**Условие перехода:** если модель не воспроизводит свободный пакет с приемлемыми ошибками на всём горизонте $t \in [0, T]$, следующие тесты не запускаются.

---

## Тест 2. Туннелирование через барьер ($\varepsilon < W$)

**Цель:** проверить, что сеть воспроизводит экспоненциально малую вероятность прохождения под барьером.

**Эталон:** формула (5) из задачи 5.4 задачника [2, стр. 158]:

$$
D = \left(1 + \frac{(k^2 + \kappa^2)^2}{4k^2\kappa^2}\,\sinh^2(\kappa d)\right)^{-1}
$$

где

$$
k = \frac{\sqrt{2m\varepsilon}}{\hbar}, \qquad \kappa = \frac{\sqrt{2m(W - \varepsilon)}}{\hbar}
$$

**Что делаем:**

1. Задаём $W, d, \varepsilon$ такие, что $\varepsilon < W$.
2. Обучаем (или запускаем дообученную) PINN.
3. Вычисляем $D_{\mathrm{PINN}}$ из решения сети при достаточно большом $t = T$:

$$
D_{\mathrm{PINN}} = \int_{d}^{L} |\Psi(x, T)|^2 \, dx
$$

4. Сравниваем с $D$.

**Критерий:** ошибка $|D_{\mathrm{PINN}} - D| < 5\%$.

---

## Тест 3. Надбарьерное прохождение ($\varepsilon > W$)

**Цель:** проверить воспроизведение интерференционных эффектов над барьером (надбарьерное отражение).

**Эталон:** формула (8) из задачи 5.2 задачника [2, стр. 149]:

$$
D = \left(1 + \frac{(k_1^2 - k_2^2)^2}{4k_1^2 k_2^2}\,\sin^2(k_2 d)\right)^{-1}
$$

где

$$
k_1 = \frac{\sqrt{2m\varepsilon}}{\hbar}, \qquad k_2 = \frac{\sqrt{2m(\varepsilon - W)}}{\hbar}
$$

**Что делаем:**

1. Задаём $W, d, \varepsilon$ такие, что $\varepsilon > W$.
2. Вычисляем $D_{\mathrm{PINN}}$ по той же формуле, что и в Тесте 2.
3. Сравниваем с $D$.

**Критерий:** ошибка $|D_{\mathrm{PINN}} - D| < 5\%$.

---

## Тест 4. Резонансное прохождение через яму

**Цель:** проверить воспроизведение резонансов и чётности волновых функций внутри ямы.

**Эталон:** формула (2) из задачи 5.3 задачника [2, стр. 150]:

$$
D = \left(1 + \frac{(k_1^2 - k_2^2)^2}{4k_1^2 k_2^2}\,\sin^2(2k_2 a)\right)^{-1}
$$

где

$$
k_1 = \frac{\sqrt{2m\varepsilon}}{\hbar}, \qquad k_2 = \frac{\sqrt{2m(\varepsilon + U_0)}}{\hbar}
$$

**Что делаем:**

1. Задаём $U_0$ и $a$.
2. Выбираем энергию $\varepsilon$ так, чтобы выполнялось условие резонанса:

$$
2 k_2 a = \pi n, \quad n = 1, 2, 3, \ldots
$$

3. Вычисляем $D_{\mathrm{PINN}}$ — он должен быть близок к 1.
4. Сравниваем с $D$ по формуле.

**Критерий:**

- $D_{\mathrm{PINN}} \sim 1$ (визуально и численно).
- Волновые функции внутри ямы имеют определённую чётность: чётные $\sim \cos(k_2 x)$, нечётные $\sim \sin(k_2 x)$ (см. пункт (6) задачи 5.3). Сравниваем профиль $|\Psi(x, t)|^2$ из PINN с аналитическим профилем внутри ямы.

---

## Тест 5. Сохранение нормы в процессе эволюции

**Цель:** убедиться, что сеть не «теряет» частицу во времени.

**Что проверяем:**

На каждом временном шаге $t_j \in [0, T]$:

$$
\left| \int_{-L}^{L} |\Psi(x, t_j)|^2 \, dx - 1 \right| < 10^{-3}
$$

Этот тест выполняется **во всех предыдущих тестах**, а не отдельно.
